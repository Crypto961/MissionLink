# ER OON Operating Model 2027 — Package

Model C is the proposal. It replaces 12 facility teams with 10 full-cycle teams and adds a 5-person US Gateway Desk that files the IDR disputes Lebanon prepares in the IDR Prep Studio.

Models A and B are included for comparison.
