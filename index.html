MissionLinkOn a mission to heal

Patient continuity and camp operations, built for the field

One record that follows a patient between missions, in Kenya, Mauritania, Peru and Lebanon — and one ledger that tracks what the camp used. Runs offline on local Wi-Fi; pick a role below to open that view. All data on this page is synthetic demo data stored only in this browser.

What's demo vs. production in this build

Local storage stands in for the self-hosted offline server; the browser's built-in speech recognition stands in for an on-device model; QR is real and scannable, NFC is represented in the UI only (it needs real hardware). None of this is hidden — every substitution is called out in code comments and in README.md, with what production would use instead.
