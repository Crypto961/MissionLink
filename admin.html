Patient data

Import from other or previous missions

CSV (one row per visit) or JSON (a MissionLink backup). Records with a pass ID that's already on file are merged into that patient's history; new visits are added, existing ones aren't duplicated. Temperatures, weights and heights may be in either metric or US units.

Real patient data: in this demo, imported records are stored only in this browser. Never upload real patient data to a public site or commit it to the repository.

Backup

Downloads everything — missions, staff, inventory, settings and patients — as one JSON file that can be imported into another device's MissionLink.
